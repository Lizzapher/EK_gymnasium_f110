passs through to terminal for creating waypoints
an image file will be created after check point selection to show what was selected
just update and copy paste

resolution and origin can be found in the yaml file

no commas for the origin position

back tick for powershell, backslash when using bash
for ease multiple args information is stored here:

python 3_Generate_Checkpoints_PGM.py `
    --image RaceTracks/berlin.png `
    --n_checkpoints 8 `
    --resolution 0.05 `
    --origin -11.606540 -26.520793 0.000000 `
    --name berlin `
    --output RaceTracks/berlin.json
